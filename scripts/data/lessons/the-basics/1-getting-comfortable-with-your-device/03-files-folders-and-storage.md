# Put Your Hands on Any Business Record in Two Minutes

> Name, file, and store your records so a lender, landlord, or tax preparer gets what they asked for the same day.

## Why this matters

Every business runs on records: licenses, receipts, invoices, insurance papers, photos of your work. Sooner or later a lender, a landlord, a customer, or a tax preparer asks for one of them, and usually they want it today. A caterer applying for a grant may be asked for her business license and last year's sales summary by five o'clock. With those files in a clearly named folder, she attaches them in two minutes and gets back to the kitchen. The same files sitting in a pile of downloads called "scan0043" can cost her the deadline. Good filing is not about being neat. It is about being ready when money is on the table.

## What you'll be able to do

- Set up a small folder structure for the business that you can keep up with
- Name every file so you know what it is without opening it
- Send the file type an office or application is asking for
- Clear your Downloads folder so nothing important gets stranded there
- Decide what lives on the device and what lives in cloud storage, so a lost phone never takes your records with it
- Find any record by search in seconds

## The lesson

### A folder structure you will keep using

Your file manager is where this work happens. On Windows it is **File Explorer**. On a Mac it is **Finder**. On an iPhone it is the **Files** app, and on Android it is usually **Files** or **My Files**. It already has Documents, Downloads, and Pictures.

Inside Documents, create one folder named for your business, and inside that, three folders: **Money**, **Legal and Licenses**, and **Customers**. Folders can hold other folders, so you can add a year inside Money or a folder per customer later. Start small. A structure with three or four folders gets used. One with thirty gets abandoned.

### Name files so you never have to open them to check

A file name should tell you what is inside. Compare "Document1" with "2026-03 Invoice 004 - Johnson." The second one tells you when, what, and who. The rule that works for almost everything is **date, then what it is, then who it is for**. Writing the date as year first, then month, keeps your files in time order when the list is sorted by name.

![The file name 2026-03 Invoice 004 - Johnson split into date, what it is, and who it is for, above two files sorted in time order](/lessons/the-basics--03-files-folders-and-storage.svg)

Keep names short and plain. Use letters, numbers, spaces, and dashes. Avoid symbols such as slashes, question marks, and colons, because some devices will not accept them and some upload systems reject them. To rename a file on a computer, right-click it and choose **Rename**. On a phone, press and hold the file and look for Rename in the menu.

### Send the file type they asked for

The letters after the dot at the end of a file name are the extension, and they identify the file type. Some devices hide the extension, but the type is still listed next to the file.

| Type | Extension | Used for |
| --- | --- | --- |
| PDF | .pdf | Finished documents that look the same everywhere |
| Word document | .docx | Letters and documents you can still edit |
| Spreadsheet | .xlsx | Budgets, price lists, and numbers |
| Image | .jpg or .png | Photos, logos, and scans |

When an application says "upload a PDF," it means this exact type, and sending the wrong one is a common reason uploads fail. Send a PDF when the document is finished and should not change, such as a signed agreement or an invoice.

### Treat Downloads as a loading dock

Anything you download from a website or save from an email lands in the **Downloads** folder unless you choose otherwise. That folder is a landing spot, not a home. Each time you download something you plan to keep, rename it and move it to the right folder that day. To move a file on a computer, drag it onto the folder, or cut it and paste it inside the folder. On a phone, press and hold the file and choose **Move**.

When you save a document from inside an app, read the folder name shown in the save window before you click Save.
### Decide where each record lives

A file saved on the device itself, called local storage, opens with no internet connection. But if the device is lost, stolen, or broken, the file is gone with it. A file in cloud storage is saved on a company's computers and reached by signing in to your account. Google Drive, iCloud, OneDrive, and Dropbox are common examples. Cloud files open from any device, and they survive if your laptop does not. The trade-offs are that you need an internet connection or a synced copy, and you must protect the account with a strong password.

For business records, the safest habit is to keep important files in cloud storage, or to keep copies in both places. Ask yourself one question about each record: if this phone went into a sink today, could I still produce this document tomorrow? You will build a full cloud filing system in the *Email & Google Drive Essentials* unit.

### Find it by search, not by scrolling

Every file manager has a search box, usually marked with a magnifying glass. Type any part of the file name. This is the payoff for good names: searching "Johnson" brings up every Johnson file in seconds, and searching "2026-03 Invoice" brings up every invoice from March.

## Try it

1. Open your file manager and go to **Documents**.
2. Create a folder named with your business name. On a computer, right-click an empty area and choose **New folder**.
3. Inside it, create three folders: **Money**, **Legal and Licenses**, and **Customers**.
4. Download the sample document from this lesson's downloads.
5. Find it in your Downloads folder and rename it using the date, what, who rule, for example **2026-01 Sample Invoice - Practice Customer**.
6. Move it into your **Money** folder.
7. Close the file manager completely. Open it again and use search to find the file by typing "Sample." You now have a business folder structure with one correctly named file inside it, and you have proven you can find it.

## Where owners lose time or money

- **Letting records pile up in Downloads.** The license you need ends up under forty menus and receipts. Rename and move each file you keep on the day you download it.
- **Keeping default names such as "Document1" or "IMG_2231."** You end up opening file after file while someone waits. Rename with date, what, and who.
- **Saving without checking where.** Read the folder name shown in the save window before you click Save.
- **Keeping the only copy on one device.** One dropped phone can erase a year of receipts. Put important business records in cloud storage or keep a second copy.
- **Building too many folders.** Filing slows down and stops. Start with three or four, and add more only when a folder gets crowded.

## Before you move on

- If your bank asked for your business license right now, could you attach it in under two minutes?
- Pick the last three files in your Downloads folder. Do their names tell you what they are?
- Which of your business records exist in only one place today? Which one would hurt most to lose?
- When a form asks for a PDF, do you know which of your documents are already PDFs and which are photos or Word files?
- Can you find last month's largest invoice by search alone?

## What you walk away with

An organized business folder with a naming rule you can reuse for every record. You can download, rename, move, and find a file in seconds, send the type that was requested, and you have decided which records belong on the device and which belong in the cloud.
