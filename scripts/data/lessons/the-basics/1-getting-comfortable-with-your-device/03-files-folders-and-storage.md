# Files, Folders, and Storage

> Name, save, move, and find your files, and understand the difference between storage on your device and storage in the cloud.

## Why this matters

Every business runs on records: licenses, receipts, invoices, insurance papers, photos of your work. Sooner or later a lender, a landlord, a customer, or a tax preparer will ask for one of them, and usually they want it today. A caterer applying for a grant may be asked for her business license and last year's sales summary by five o'clock. If those files sit in a clearly named folder, she attaches them in two minutes. If they are somewhere in a pile of downloads called "scan0043," she misses the deadline. Good filing is not about being neat. It is about being ready.

## What you'll learn

- What files and folders are, and how they fit together
- How to name a file so you can find it later
- The common file types and what each one is for
- Where downloads go and how to move them
- The difference between local storage and cloud storage

## The lesson

### Files and folders

A **file** is one saved item: one letter, one photo, one spreadsheet. A **folder** is a container that holds files and can also hold other folders. It works just like a paper filing cabinet. The cabinet is your device, the drawers are folders, and the papers inside are files.

Every computer has an app for looking through files and folders. On Windows it is called **File Explorer**. On a Mac it is called **Finder**. On an iPhone it is the **Files** app, and on Android it is usually called **Files** or **My Files**. Open it and you will see folders the device already made for you, such as Documents, Downloads, and Pictures.

### Naming files so you can find them

A file name should tell you what is inside without opening it. Compare "Document1" with "2026-03 Invoice 004 - Johnson." The second one tells you when, what, and who. A simple rule that works for almost everything is **date, then what it is, then who it is for**. Writing the date as year first, then month, keeps your files in time order when the list is sorted by name.

Keep names short and plain. Use letters, numbers, spaces, and dashes. Avoid symbols such as slashes, question marks, and colons, because some devices will not accept them. To rename a file on a computer, right-click it and choose **Rename**. On a phone, press and hold the file and look for Rename in the menu.

### Common file types

The letters after the dot at the end of a file name are called the **extension**. They tell you, and the device, what kind of file it is. Some devices hide the extension, but you can still see the type listed next to the file.

| Type | Extension | Used for |
| --- | --- | --- |
| PDF | .pdf | Finished documents that look the same everywhere |
| Word document | .docx | Letters and documents you can still edit |
| Spreadsheet | .xlsx | Budgets, price lists, and numbers |
| Image | .jpg or .png | Photos, logos, and scans |

When an application says "upload a PDF," this is what it means. The file type matters, and sending the wrong type is a common reason uploads fail.

### Downloads

To **download** means to copy a file from the internet onto your device. Unless you choose otherwise, downloaded files land in the **Downloads** folder. That folder is a landing spot, not a home. Think of it like the mail pile by the front door. Each time you download something you plan to keep, rename it and move it to the right folder. To move a file on a computer, drag it onto the folder, or cut it and paste it inside the folder. On a phone, press and hold the file and choose **Move**.

### Local storage and cloud storage

**Local storage** means the file is saved on the device itself. You can open it with no internet connection, but if the device is lost, stolen, or broken, the file is gone with it. **Cloud storage** means the file is saved on a company's computers and you reach it over the internet by signing in to your account. Google Drive, iCloud, OneDrive, and Dropbox are common examples. You can open cloud files from any device, and they survive if your laptop does not. The trade-offs are that you need an internet connection or a synced copy, and you must protect the account with a strong password.

For business records, the safest habit is to keep important files in cloud storage, or to keep copies in both places. You will build a full cloud filing system in the *Email & Google Drive Essentials* unit.

### Finding a file again

If you cannot find a file, use **search**. Every file app has a search box, usually marked with a magnifying glass. Type any part of the file name. This is the payoff for good names: searching "Johnson" finds every Johnson file in seconds.

## Try it

1. Open your file app and go to **Documents**.
2. Create a new folder and name it with your business name. On a computer, right-click an empty area and choose **New folder**.
3. Inside it, create three folders: **Money**, **Legal and Licenses**, and **Customers**.
4. Download the sample document from this lesson's downloads.
5. Find it in your Downloads folder and rename it using the date, what, who rule, for example **2026-01 Sample Invoice - Practice Customer**.
6. Move it into your **Money** folder.
7. Close the file app completely. Open it again and use search to find the file by typing "Sample." You now have a business folder structure with one correctly named file inside it, and you have proven you can find it.

## Common mistakes

- **Leaving everything in Downloads.** Rename and move each file you keep on the day you download it.
- **Keeping default names such as "Document1" or "IMG_2231."** Rename with date, what, and who.
- **Saving without noticing where.** When you save, read the folder name shown in the save window before you click Save.
- **Keeping the only copy on one device.** Put important business records in cloud storage or keep a second copy.
- **Making too many folders.** Start with three or four. Add more only when a folder gets crowded.
